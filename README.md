# Water Tank Alarm Using BC547

1. Description
A simple water tank level indicator and overflow alarm using BC547 transistors.

2. Components
- BC547 Transistors ×4
- LEDs ×3
- Buzzer
- 220Ω Resistors ×6
- 9V Battery
- Water Level Sensing Probes

3. Working
The water level is detected using sensing probes A, B, C
and D. As the water level rises, the corresponding BC547
transistors turn ON and indicate the water level using LEDs.
At the highest level, the buzzer is activated.

4. Water Level Indication
- A → Low level
- B → Medium level
- C → High level
- D → Full level + Buzzer
